# AI Team Starter (plugin `ai-team`, tiếng Việt)

Dựng đội AI riêng trong folder làm việc, trên Claude và Codex. Cài xong, AI mời bạn trả lời tối đa 5 câu rồi dựng:

- `AGENTS.md` — hiến pháp: luật tổng quát (Claude + Codex cùng đọc), AI không tự sửa
- `CLAUDE.md` — chỉ `@AGENTS.md` + `@START-HERE.md`
- `START-HERE.md` — bản đồ folder: cây thư mục, việc gì đọc file nào, danh bạ trợ lý, bảng dự án
- `nguoi-dung/` — hồ sơ người dùng (`ve-toi.md`) và giọng văn (`van-phong.md`)
- `bo-nho/` — bài học, kiến thức theo chủ đề, nhật ký từng phiên, việc đang dở

Gọi thêm khi cần: `them-tro-ly` (trợ lý theo format chuẩn 9 mục), `them-du-an` (dự án có nguồn sự thật), `sap-xep-thu-muc` (dọn thư mục, không xoá), `luu-phien` (lưu phiên — AI tự chạy cuối mỗi việc), `ghi-bai-hoc`, `don-bo-nho`, `kiem-tra` (chỉ đọc). Không thấy lời mời thì gõ `/bat-dau`.

Hướng dẫn đầy đủ: README ở gốc repo.
