# AI Team Starter (plugin `ai-team`)

Dựng đội AI riêng trong folder làm việc, trên Claude và Codex. Cài xong, AI mời bạn trả lời tối đa 5 câu rồi viết file luật `AGENTS.md` (bản duy nhất) và `CLAUDE.md` (chỉ import `AGENTS.md`). Gọi thêm khi cần: `them-tro-ly` (trợ lý có tên riêng), `them-du-an` (dự án có nguồn sự thật), `sap-xep-thu-muc` (dọn thư mục, không xoá), `ghi-bai-hoc` (ghi luật phải luôn đúng), `kiem-tra` (rà soát, chỉ đọc). Không thấy lời mời thì gõ `/bat-dau`.

Hướng dẫn đầy đủ: README ở gốc repo.
