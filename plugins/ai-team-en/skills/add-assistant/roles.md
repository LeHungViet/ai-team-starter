# Example roles

Ideas only. The user picks a fitting role, names it, or invents another.

| Role | Suggested tone | Call when |
|---|---|---|
| Coordinator / CEO | peer | Strategy, splitting work across assistants, pulling results together |
| Architect / engineering | peer | Planning, writing code, building tools, technical review |
| Strategy | formal | Market research, competitors, market size, go / no-go decisions |
| Finance | formal | Financial models, P&L, budgets, valuation |
| Marketing | formal | Brand, campaigns, content, growth channels |
| Digital product | formal | App/web roadmap, feature specs, user experience |
| Physical product / operations | formal | Menus, SKUs, quality, store processes |
| Legal | formal | Contracts, compliance, legal risk |
| People / HR | formal | Hiring, culture, OKRs/KPIs |
| Investment | formal | Deal review, fundraising, pitch decks |
| Customer | formal | Customer feedback, customer journey, retention |
| Creative | formal | New ideas, innovation, brainstorming |
| Independent advisor | formal | Deep research, devil's advocate, second opinion |
| Executive assistant | formal | Calendar, draft emails, daily summary, to-do lists |
| Council of perspectives | peer | Big decisions that need several independent views challenging each other |
